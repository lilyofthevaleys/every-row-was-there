# Every row was still there

An incident walkthrough: how a renamed form column silently wiped 12,247 CV links from a live recruitment data pipeline while every existing check passed, and the per-funnel content-coverage guard that now makes this kind of failure loud. Includes an interactive simulation of the three scenarios.

**Live page:** https://lilyofthevaleys.github.io/every-row-was-there/

The pipeline was built by an intern team at Eterna Indonesia; this page covers my part, the incident fix. Internal names and all candidate data are omitted.
